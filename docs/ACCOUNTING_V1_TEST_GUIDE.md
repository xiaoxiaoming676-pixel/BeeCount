# BeeCount 智能记账 V1：红米体验包安装与验收

## 下载和安装

1. 打开 [Actions 构建 #3](https://github.com/xiaoxiaoming676-pixel/BeeCount/actions/runs/35952628945)，在页面底部 **Artifacts** 下载 `accounting-v1-dev-debug-3` 压缩包，解压后找到 `app-dev-debug.apk`。
2. 将 APK 传到红米手机，使用“文件管理”打开；系统如提示，请仅为当前文件管理应用允许“安装未知应用”。安装后的名称为“蜜蜂记账测试版”，与正式版的包名不同。
3. 打开应用，完成它本身的首次启动步骤。在“关于”查看 `accounting-v1-debug`、构建号和提交号，反馈问题时同时提供 Android/HyperOS 版本和复现步骤，不发送真实账单或含敏感数据的日志。

## 本包可验证的功能

- 手动添加一笔支出、一笔收入，修改并删除其中一笔；对照首页与统计页确认金额正确。
- 从首页进入“文字记账”，输入“今天午饭35、打车18块5、昨天水果26”。应生成三条待核对草稿，分别为 35.00、18.50、26.00 元。点开草稿核对金额、日期、类型与备注，逐笔保存，再检查原有交易列表和统计页。
- 输入“上个月花了80”、“转账100”及“今天买了东西”，确认缺少明确日期、转账账户或金额时不会直接入账；修改草稿后再保存。转账请使用原有表单。
- 在“我的 → 数据管理 → 导出数据”导出账本；保留导出文件，在“导入数据”中检查导入流程。**先使用空测试账本**演练恢复，核对交易笔数与金额后再处理真实数据。原有备份与恢复流程尚未完成本轮实机验收。

## 本包尚不能验收的项目

- 语音暂可用手机系统输入法的语音转文字输入到文字记账框；应用内独立语音入口尚未接入。
- 微信、支付宝通知自动入账、持久队列及跨来源去重尚未实现，当前包不会自动生成此类交易。无需授予“通知使用权”或为了本功能修改自启动、后台限制。
- 本包在云端以 Android 调试证书签名；后续构建若签名证书变化，Android 可能拒绝直接覆盖安装。卸载会删除该测试版的本地数据。**保存账本导出文件并确认可恢复前，不要卸载或升级。**稳定签名及无损升级需后续验证。

## 下一包需要红米实机验收

待语音与通知模块完成并交付更新 APK 后，再核对麦克风授权、通知使用权、微信/支付宝真实通知、相同金额不同交易、重复通知、锁屏、关闭应用、重启手机、自启动与后台限制。仅在实际使用相应功能时按页面说明授权；不需要通讯录、短信或无关敏感权限。检查统计、预算、导出恢复及升级后的账本完整性。
